# Fotografias provisórias

As imagens locais são ilustrativas. As variantes WebP de 400 e 660 pixels foram geradas a partir dos PNGs originais para servir imagens responsivas com `srcset`. Não representam o profissional responsável, alunos, relatos ou resultados.

- `public/assets/images/athlete.png`: https://github.com/codewithsadee/fitlife/blob/master/assets/images/hero-banner.png
- `public/assets/images/coach.png`: https://github.com/codewithsadee/fitlife/blob/master/assets/images/about-banner.png

O README da fonte declara o projeto livre para uso, sem licença formal: https://github.com/codewithsadee/fitlife#license. Este projeto não atribui identidade ou endosso aos modelos. Antes da publicação comercial, substitua por fotografias reais autorizadas e verifique os direitos de imagem aplicáveis.

As fontes Barlow Condensed e Manrope são hospedadas localmente pelos pacotes Fontsource (SIL Open Font License nos respectivos pacotes). Não há chamadas para Google Fonts, Instagram ou serviços de imagens durante a navegação.
