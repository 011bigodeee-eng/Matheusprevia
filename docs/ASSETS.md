# Fotografias de referência

As imagens atuais mostram exercícios e ambiente de treino. São referências ilustrativas, não retratos do profissional, alunos ou resultados deste projeto.

- `public/assets/images/training-600.webp` e `training-1170.webp`: variantes responsivas da fotografia https://github.com/codewithsadee/fitlife/blob/master/assets/images/video-banner.jpg
- `public/assets/images/practice.webp`: https://github.com/codewithsadee/fitlife/blob/master/assets/images/class-1.jpg

A composição anterior usava atletas recortados. Esses arquivos foram retirados da revisão editorial. As imagens atuais têm tratamento visual de escala de cinza via CSS, preservando os originais de referência sem atribuir identidade aos modelos.

O README da fonte declara o projeto livre para uso, sem licença formal: https://github.com/codewithsadee/fitlife#license. Não se presume endosso dos modelos. Antes da publicação comercial, substitua as referências por fotografias autorizadas do profissional e verifique os direitos de uso das imagens definitivas.

Edite `src/config/site.ts` para alterar arquivos, `srcset`, textos alternativos e `images.illustrative`. Este último controla as identificações de imagem ilustrativa. Não o desative antes de inserir imagens reais autorizadas.

Barlow Condensed e Manrope são hospedadas localmente pelos pacotes Fontsource (SIL Open Font License nos respectivos pacotes). Nenhuma imagem ou fonte depende de um serviço externo durante a renderização.
